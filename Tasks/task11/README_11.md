# Гоцкало Максим, 212 группа

Все это **task 11*  

В этом задании необходимо было разобраться с генератором синтаксических анализаторов yacc и выполнить 2 задания - построить программу, вычисляющую протяжение скобочной системы, и построить программу-калькулятор. Надо построить грамматику с необходимыми семантическими действиями. В Makefile программы на языке yacc сначала подаются на вход соответствующей программе, в результате чего получаются синтаксические анализаторы на языке Си. Далее можно запустить эти анализаторы и проверить их работу на входных данных.  

## Программы: 

1. **prog1.y**  
    Программа на языке yacc для вычисления протяжения скобочной системы. Идея такова, что есть верхний уровень скобок, а есть остальные более глубокие вложенные скобки. Необходимо посчитать именно количество пар скобок верхнего уровня.  

2. **prog2.y**  
    Программа на языке yacc для реализации работы калькулятора. Входное выражение разбивается на выражения в скобках, слагаемые, множители и сами числа. Таким образом можно однозначно распознать любое такое арифметическое выражение и, выполнив необходимые семантические действия, посчитать его результат.

# Гоцкало Максим, 212 группа

Все это **task 3**

## Программы:

1. **task3_f.c**  
   В этом модуле дается описание структуры "список слов" (как массив указателей на char) и функций работы с ней, а также необходимые переменные и функции для работы основной программы

2. **task3_1.c**  
    Основная программа, в этом модуле реализована работа графа по обработке вводимых строк до конца файла (ввод блоками по N символов), необходимо разбить строку на отдельные слова, включая спецслова, сохранить слова в массив, вывести и отсортировать его
    
3. **Makefile**  
    Файл для компиляции многомодульной программы (через make task3)

3. **task3.h**  
    Файл с общими функциями для task3_f.c и task3_1.c

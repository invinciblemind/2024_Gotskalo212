# Гоцкало Максим, 212 группа

Все это **task 8**

## Программы:

Выбранный вариант задания - 4.1 (вещественная матрица). Цель задания - реализовать абстрактный тип данных (АТД), в котором будут реализованы необходимые методы работы с данной структурой данных.  

1. **matrix.h**  
    В этом заголовочном файле описан общий вид класса Matrix, а также базового для него класса Errors - класса ошибок.  
    Класс ошибок нужен для обработки исключений. В этих классах описанны члены классов (в приватной секции) и прототипы методов классов. В файле сразу определен конструктор по умолчанию для данного класса - создание пробельной строки.  
    Также в этом файле описана структура Cell - единица матрицы, в которой хранится элемент - вещественное число, и два указателя на нижний и правый элементы матрицы. Единственным же членом класса  Matrix является указатель на первую такую клетку. В этом файле сразу определен конструктор по умолчанию - инициализация указателя нулевой ссылкой.  
    При этом матрица имеет такой вид, что сначала создается первая строка, далее к самому левому элементу присоединяется снизу новый и от него вправо создается новая строка и т.д..  
    Отдельно вне класса вынесена дружественная функция (прототип) вывода на экран матрицы.
2. **matrix.cpp**  
    В этой программе реализованы все функции из файла matrix.h.  
    Для класса Errors необходим лишь конструктор преобразования строки в элемент класса, в котором полученная строка переносится в поле error_msg, и функция, возвращающая это самое поле.  
    В классе Matrix реализованы следующие функции:  
        1) возврат указателя на первую клетку матрицы  
        2) копирование получаемой матрицы в эту, копирование глубокое - по каждому указателю  
        3) очистка всей матрицы - удаление всех ее клеток, причем функция может быть применена к объекту несколько раз  
        4) конструктор копирования, использующий соответствующую функцию  
        5) оператор присваивания с предварительным уничтожением прошлого содержимого и поуказательного копирования  
        6) конструктор преобразования, получающий на вход размеры матрицы и может быть ее элемент. Создает матрицу данных размеров заполняя ее 0 или полученным элементом. Может выбросить исключение, если размеры неположительные.  
        7) конструктор преобразования, получающий на вход одно число и строящий единичную матрицу (одну клетку) с данным элементом.  
        8) конструктор преобразования, получающий на вход массив значений и его длину. Создает матрицу-строку с этими элементами, предварительно очищая старое и используя предыдущую функцию создания и функцию set. Может выбросить исключение, если размер неположительный.  
        9) конструктор преобразования, получающий на вход длину массива значений и сам массив. Аналогично предыдущему, но создает столбец.  
        10) конструктор преобразования, получающий на вход строку - строковое представление матрицы. Создает матрицу по этому представлению. Аккуратно поэлементно считываем строку и создаем клетки матрицы. Много где может выбросить исключение, если строка не соответствует шаблонной.  
        11) деструктор класса, использующий функцию очистки матрицы.  
        12) статическая функция создания единичной матрицы получаемого размера n, если он неположительный, выбрасывает исключение. Используют создание нулевой матрицы размера nxn, и заполняет диагональные элементы 1.  
        13) статическая функция создания диагональной матрицы получаемого размера n, заполняемой получаемым массивом чисел, если n неположительное, выбрасывает исключение. Работает аналогично единичной.  
        14) возврат количества строк матрицы через проход по указателям.  
        15) аналогичный возврат числа столбцов.  
        16) установка в элемент матрицы по двум индексам нового числа. Доходит до нужного места по указателям и меняет число. Выбрасывает исключение, если индексы выходят за границы матрицы.  
        17) операция [], берущая по получаемому индексу данную строку, если есть (1-й приоритет), или данный столбец, если есть (2-й приторитет). Если в матрице уже одна строка, то сразу выдает столбец (нужно для двойного приенения операции). Если индекс не соответствует ни номеру строки, ни номеру столбца, выбрасываетя исключение. Если же индекс корректный, соддается новая матрица-строка/столбец и по указателям заполняется элементами исходной матрицы.  
        18) операции умножения и умножения с присваиванием, умножение на скаляр. Каждый элемент матрицы умножается на полученный скаляр, возможно с созданием новой матрицы.  
        19) дружественная операция вывода матрицы. По указателям перебираются все элементы и печатаются через пробелы и переводы строки.  

3. **main.cpp**  
    Это тестирующая программа, использующая наш класс матриц. Сначала запускаются 12 тестов на все возможные функции класса, далее пользователю предлагается выбрать тест для самостоятельного тестирования, в частности для проверки исключений.  
    В каждом тесте либо создается новый объект класса матрицы и с ним произходят некоторые действия, либо что-то делают с уже созданной ранее матрицей, далее она или результат работы функции выводится на экран.  
    Программа разбиты на блоки try-catch, если в процессе работы выбросилось исключение, то оно обработается в catch, иначе программа отработает в try.

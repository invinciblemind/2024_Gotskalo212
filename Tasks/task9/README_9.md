# Гоцкало Максим, 212 группа

Все это **task 9*  

В этом задании реализована иерархическая структура классов, моделирущая дерево танков. Реализовано 14 различных танков и более 20 орудий. Есть 1 абстрактный класс с тремя чистыми виртуальными функциями, наследником которого является класс Tank, в котором эти функции частично реализованы. Наследниками класса Tank являютя конкретные 14 класса танков, в которых все функции доделаны. Также есть общий класс Gun, наследниками которого являются все орудия. Классы танков также наследуют определенные классы орудий. Над танками могут применяться некоторые функции в основной программе.  

## Программы: 

1. **Abs_Class_print.h**  
    Абстрактный класс с тремя чистыми виртуальными функциями:  
    - print() - для вывода информации о танке  
    - install_gun(int number) - для установки на танк конкретного орудия  
    - print_about_guns() - для вывода информации о всех орудиях танка  

2. **Class_Gun.h и Class_Gun.cpp**  
    Заголовочный файл класса и программа с реализацией функции. У всех орудий игры есть такие характеристики, как название, урон, время перезарядки и пробитие. Все эти данные вынесены в этот общий класс. Функция print_gun_info() печатает всю эту информацию о конкретном орудии, также печатая ДПМ.  

3. **Много файлов вида Class_..._gun.h и .cpp**  
    Все это файлы орудий, являющихся наследниками класса Gun. В заголовочных файлах указана структура класса, в программах - реализация конструктора по умолчанию, который заполняет все поля характеристик орудия соответствующей информацией.  

4. **Class_Tank.h и .cpp**  
    Файлы с заголовком и реализацией общего класса всех танков Tank. В структуре класса описаны элементы, хранящие прочность, урон, перезарядку, броню, пробитие и название конкретного танка. Также в состав класса входят виртуальные функции абстрактного класса, причем две из них еще не реализуются. Наконец, здесь описаны и реализованы две функции боя между танками - PvP и Battle.  
    Виртуальная функция print частично реализована в этом классе - она выводит все описаные выше характеристики танка, вместе с ДПМом.  
    Функция PvP моделирует сражение между двумя танками на основании их характеристик. Вначале выводится информация о танках, далее в цикле for имитируется течение времени (переменная ttime). Когда время достигает времени перезарядки одного из танков, производится выстрел - выводится время, имена танков с прочностью того, по кому стреляют, специальным образом вычисляется шанс непробития и погрешность разового урона и выводится результат выстрела. Если прочность одного из танков на нуле, выводится сообщение о победе второго танка. Текущее время выводится примерно раз в секунду.  
    Функция Battle является расширением PvP, но уже до размера 7 на 7. Вместо танков в функцию передаются команды - массивы танков, а также стратегии команд. После вывода информации о командах как в PvP имитируется течение времени. В цикле for запускается еще 2 цикла, в которых проверяется, подошло ли время перезарядки конкретного неуничтоженного танка одной из команд. Если да, то в зависимости от стратегии команды выбирается номер вражеского танка, который будет атакован. Стратегия random означает случайный выбор одного неуничтоженного танка противников, focus - выбор противника с наименьшим здоровьем, damage - с наибольшим. После выбора цели производится выстрел, как в PvP. При уничтожении танка выводится информация о текущей прочности команд. Если вся вражеская команда уничтожена, выводится сообщение о победе и выход из циклов.  

5. **14 пар файлов вида Class_имя_танка.h и .cpp**  
    Это файлы конкретных танков, наследующих класс Tank и виртуально наследуя конкретные классы орудий. В описание класса входят конструктор по умолчанию и виртуальные функции класса Tank.  
    В конструкторе заполняются все поля характеристик танка из класса Tank, берется орудие по умолчанию.  
    Функция install_gun(number) устанавливает орудие в соответствии с полученым номером, нумерация орудия доступна по функции print_about_guns.  
    Функция print выводит дополнительную несохраняемую информацию о танке - уровень и тип, и вызывает такую же функцию уже из класса Tank.  
    Функция print_about_guns выводит информацию о всех доступных танку орудиях с нумерацией.  

6. **game.cpp**  
    Программа для тестирования данного задания. Создаются все танки игры, несколько перопределенных команд танков, далее пользователю предлагается вводить тестирующие команды, описание которых выводится перед вводом команды. Пока команда не будет 0 - выход из цикла, она будет классифицироваться операторами switch-case и в конечном счете будет выполняться соответствующая команда.  

6. **Makefile**  
    В начале даны все объектные файлы и заголовки, далее создаются все объектные файлы для cpp-программ, потом создается исполняемый файл task9. С помощью цели test происходит вызов данного файла через valgrind, цель clean - удаление объектных и исполняемого файлов.

# Гоцкало Максим, 212 группа

Все это **task 4**

## Программы:

1. **task4_echo.c**  
   Моделирует команду echo - выводит на экран полученные аргументы в командной строке, флаг -n - не выводить перевед строки

2. **task4_pwd.c**  
       Моделирует команду pwd - выводит на экран имя текущей директории

3. **task4_ls.c**  
       Моделирует команду ls - выводит все файлы текущей директории, флаг -l - расширенный вывод, флаг -g - имя группы владельца, -R - также вывести все файлы подкаталогов
    
4. **task4_cp.c**  
       Моделирует команду cp - копирует содержимое первого файла, полученного в командной строке, во второй

5. **task4_cmp.c**  
       Моделирует команду cmp - сравнивает содержимое двух входных файлов, выдает место первого различия

2. **task4_od.c**  
       Моделирует команду od - выводит содержимое файла по 10 символов в строке, с нумерацией, флаг -b - выводить восьмеричные коды символов

Все это **task 5**

## Программы:

1. **task3_1.c**  
   Модифицированная аналогичная программа из task 3 (считывает со стандартного входного потока строку, разделяет ее на слова и формирует из них список). Также реализованы специальные символы:  
    • кавычки (позволяют вставить пробел в аргумент или имя программы), например:  
        cat ”new file” – вывести на экран файл с именем ”new file”  
    • \ (экранирование символа, отменяет специальное действие последующего символа, например \” трактуется как собственно символ кавычка, а не ограничитель закавыченной подстроки), последовательность \\ позволяет ввести обычный одинарный слеш  
    • комментарии: при наличии во входной строке символа # (не внутри кавычек, не экранированного обратным слешем) все символы, стоящие после решётки игнорируются.  

2. **task3_f.c**  
    Модифицированная аналогичная программа из task 3 (набор функций для работы со списком слов в task3_1.c)

3. **task3.h**  
    Модифицированный аналогичный файл из task 3 (объявление глобальных функций для двух предыдущих программ)
    
4. **task5_tree.c**  
       1 этап task 5 - создание дерева команд по входной строке.  
       Структура дерева (struct cmd_inf):  
            argv - список из имени команды и аргументов  
            infile -  переназначенный файл стандартного ввода  
            outfile - переназначенный файл стандартного вывода  
            int outfile_index -  =0, если указан > (запись в начало файла), =1, если указан >> (запись в конец файла)  
            backgrnd - =1, если команда подлежит выполнению в фоновом режиме  
            next_exit_mode - =0, если не было || и &&, =1, если был ||, =2, если был &&  
            psubcmd - команды для запуска в дочернем shell  
            pipe - следующая команда после “|”  
            next - следующая после “;” (или после “&”)  
        Далее идут функции работы со списком lst_of_args, состоящим из текущих аргументов - слов из введенной строки, не являющихся специальными:  
            clearlist_of_args() - очистить список (освободить все указатели на слова и указатель на список)  
            null_list_of_args() - обнулить список (а также его размер и последний индекс)  
            printlist_of_args() - печать списка  
            copy_list(int flag) - копирует lst_of_args в tree_pointer[cur_tree_p_ind]->argv - указатель на аргументы текущего процесса (под них выделяется новая динамическая память)  
            termlist_of_args() - завершает список (выравнивает память)  
            addword_of_args(str) - добавление в список нового слова (с проверкой на 4 особые переменные: $HOME, $SHELL, $USER, $EUID)  
            tree_writer(name, i, outfile_ind) - запись в дерево, в зависимости от name (argv, infile, outfile) переносим данные в дерево из lst_of_args или из lst_copy - результат работы task3  
            tree_free(pointer) - полное освобождение дерева  
            print_tab(level) - вывод нужного числа отступов  
            print_tree(pointer, level) - вывод всего дерева (всех параметров и всех поддеревьев)  
            Сначала в цикле while в lst_copy возвращается результат работы функции task3() - та, что из task3_1 возвращает список слов, далее - начальная инициализация дерева, потом в цикле for идет обработка всех слов:  
                    & - записывается в backgrnd 1 и создается звено next следующего поддерева  
                    && - создается звено next следующего поддерева и записывается в next_exit_mode 2  
                    || - создается звено next следующего поддерева и записывается в next_exit_mode 1  
                    ; - создается звено next следующего поддерева  
                    | - создается звено pipe следующего поддерева  
                    ( - в массиве указателей на деревья tree_pointer создается новый указатель, которому соответствует звено psubcmd следующего поддерева  
                    ) - завершается psubcmd  
                    < - name = "infile"  
                    > - name = "outfile"; outfile_ind = 0  
                    >> - name = "outfile"; outfile_ind = 1  
                    иначе - текущее слово - аргумент (имя файла, программы и т.п.), происходит запись в дерево  
            
            Потом список завершается.  
5. **launch_tree.c**
        2 этап task 5 - запуск дерева  
        Функции:  
            cd - реализация команды cd, переход в соответствующую папку  
            chck_status - проверка статуса завершения команды  
            simple_command - запуск простой команды: либо cd, exit или pwd - реализуются отдельно, либо через execvp  
            command - запускается простаю команда или subshell  
            conveyer - запускается команда или конвейер с дальнейшим запуском следующего звена  
            launch_tree - запускает конвейер и следующее звено  
            exit_status - возвращает exit_stat (=1, если был exit, и =0 иначе)  
        Из основной программы task5_tree.c после создания дерева запускается launch_tree, которая реализует его.  
        Потом в task5_tree.c дерево и список очищаются, происходит проверка завершения и, если не было exit, while повторяется заново, пока не будет введен EOF

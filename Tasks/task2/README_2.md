# Гоцкало Максим, 212 группа

Все это **task 2**

## Программы:

1. **task2-1.c**  
   Вводится eps, далее вводится вещ. числа до конца файла и для каждого числа выводится его квадратный корень, вычисленный итерационным методом с точностью eps

2. **task2-2-1.c**  
    Вводится x, далее до конца файла вводятся коэффициенты многочлена от a_n до a_0 (при x с соответствующими степенями от n до 0), программа итерационно вычисляет значение многочлена в точке x
    
3. **task2-2-2.c**  
    Модификация task2-2-1.c, также выводится значение производной данного многочлена в точке x

4. **task2-2-3.c**  
    Модификация task2-2-2.c, также выводится значение определенного интеграла с пределами интегрирования от 0 до x в точке x (теперь вводится n, x, a_n,...,a_0)

5. **task2-3.c**  
    Реализованы 2 функции вычисления i-ого числа Фибоначчи - итеративная и рекурсивная, в программе до конца файла вводится очередное целое i>=0 и выводятся результаты работы 2-ух функций

6. **task2-4.c**  
    Вводится вещественное число как строка (по правилам определения вещественной константы в Си), необходимо вывести это число как число (игнорируя l/L/f/F)
    + реализован r/R - обратный к e/E

7. **task2-5.c**  
    Вводится строка из непустых слов, разделенная пробелами/табуляцией. необходимо в динамической памяти сохранить список слов, удалить из него все слова, совпадающие с последним (кроме самого последнего слова) и вывести полученный список слов на экран
    
8. **task2-6.c**  
    Вводятся следующие команды, разделенные ПП, необходимо создать дерево поиска (динамический объект) и реализовать следующие действия:
        +число - добавить число в дерево
        -число - удалить число из дерева
        ?число - проверить, есть ли число в дереве

9. **task2-7.c**  
    Необходимо дополнить программу-калькулятор операциями вычитание, целочисленное деление и возведение в степень (правоассоциативна) (сложение и умножение уже реализованы), с нужными приоритетами  и по нужной грамматике выражений.

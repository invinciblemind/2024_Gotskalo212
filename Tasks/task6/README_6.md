# Гоцкало Максим, 212 группа

Все это **task 6**

## Программы:

1. **task6.c**  
   Задание - обедающие философы (семафоры)  
   Реализовано через принцип: сначала каждый стул-семафор равен 2, садящийся философ уменьшает свой фемафор на 2, а соседние на 1.
   В программе реализовано взаимодействие N процессов через массив семафоров IPC.  
   В основной функции main создается ключ - доступ к IPC-объекту, потом создается массив N семафоров с ИД semid. Также настраивается обработка сигнала SIGINT, для перерывания процессов. Далее в цикле создается N процессов - философов. 
   Функция-обработчик kill_philosophers - убивает все N процессов (через массив PID-ов).   
   Функция philosopher - в бесконечном цикле каждый философ сначала думает (функция think), далее пытается сесть (sit), потом ест (eat), потом встает (wake).  
   Функция think - начинает думать (вывод), потом спит некоторое время, потом заканчивает думать (вывод).  
   sit - настраивается массив sops на операции уменьшения семафоров, потом пытается выполниться операция.
   eat - ест (вывод, спит, вывод)  
   wake - поднимает соответствующие семафоры
